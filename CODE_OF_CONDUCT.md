# Code of Conduct

Akshar exists so that everyone can write in their own language. This is a **toy project** built for fun, learning, and wild experimentation! We want to keep this community open, welcoming, and completely stress-free for everyone—regardless of your experience level.

## We expect

- Respectful, patient and kind communication — especially with beginners.
- Respect for every language and script. Corrections from native speakers are valued.
- Constructive feedback: criticise the work, not the person.
- Assuming good intent; asking before assuming.

## We do not accept

- Harassment, insults, discrimination or personal attacks.
- Sexual language or unwelcome attention.
- Publishing others' private information.
- Mocking anyone's language, accent, or level of skill.

## Enforcement

To protect everyone's privacy and keep our conversations open, **we do not use personal email or private messaging** for this project.

- **Where to chat:** All questions, feature ideas, support requests, and casual conversations happen strictly in the **GitHub Discussions** tab of this repository.
- **How to report issues:** If you find a bug, please open a public **GitHub Issue**.
- **Safety & Enforcement:** If you witness behavior that goes against this Code of Conduct, please flag it or start a discussion thread so we can address it together as a community.

Let's keep things fun, open, and keep building cool stuff together!
