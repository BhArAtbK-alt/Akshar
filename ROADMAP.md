# Roadmap — open goals anyone can take

Pick one, comment on its issue, and go. 🟢 = good first issue.

## Languages & words
- 🟢 Grow the word lists (Hindi ≈170, Japanese ≈95 — aim for 1000+)
- 🟢 Native-speaker review: Tamil, Korean, Arabic, Urdu, Bengali, Telugu, Kannada, Malayalam
- New languages: Nepali, Sinhala, Thai, Hebrew, Persian, Ukrainian, Sanskrit, Burmese, Khmer
- Hindi: smarter schwa deletion (`bharat` → भारत automatically)
- Japanese: real kana→kanji conversion beyond lexicon candidates

## Platforms & packaging
- Fcitx5 backend (reuse `engine/session.py`)
- Windows and macOS input methods
- `.deb`, Arch AUR, Fedora RPM, Flatpak
- Wayland-specific testing across GNOME / KDE / Sway

## Features
- GUI settings app (hotkeys, languages, word-list editor)
- Emoji and symbol shortcuts (`:heart:`)
- Import/export of the personal dictionary
- Better offline translation model management
- Auto-switch language per application

## Quality
- Benchmark and speed tests
- More real-IBus integration tests (candidates, translate mode)
- README translations (Hindi, Tamil, Japanese …)
